# BC Market

Fullstack marketplace application built with:

- Next.js
- Node.js
- Express
- PostgreSQL

---

## Architecture

This project uses a monorepo structure:

```plaintext
apps/
  frontend/
  backend/

docs/
```

---

## Applications

### Frontend

Next.js application located in:

```plaintext
apps/frontend
```

### Backend

Express API located in:

```plaintext
apps/backend
```

---

## Getting Started

### Clone the project

```bash
git clone https://github.com/bryancv-super/bc-market
```

### Install dependencies

```bash
npm install
```

### Run frontend

```bash
npm run dev:frontend
```

### Run backend

```bash
npm run dev:backend
```

### Run full development environment

```bash
npm run dev
```
