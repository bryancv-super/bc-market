# Flow Diagrams

This directory contains the main application flow diagrams for BC Market.

Flow diagrams are used to represent complex user interactions and business processes across the system.

## Purpose

These diagrams help visualize:

- User interaction flows
- Authentication processes
- Shopping list workflows
- Navigation structure
- System behavior during critical operations

## Included Flows

- Authentication Flow
- Recover Password Flow
- Create Shopping List Flow
- Add Product To List Flow
- Shopping Session Flow
- Navigation Flow

## Notes

Flow diagrams are focused on process visualization and user interaction logic.

Simple CRUD operations are intentionally excluded to avoid unnecessary diagram redundancy.
